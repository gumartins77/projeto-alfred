## Animações & Transições

```
Focus States:
- Inputs:        ring-2 ring-blue-500 (border destacado)
- Hover:         hover:bg-blue-700 (mais escuro)
- Disabled:      bg-gray-400 (desabilitado)

Feedback:
- Loading:       "Gerando...", "Salvando..."
- Success:       alert('Sucesso!')
- Error:         alert('Erro: ...')

Smooth Transitions:
- Button hover:  transition (fade suave)
- All elements:  outline-none transition (foco suave)
```

## Responsividade

```
BREAKPOINTS:

Mobile:    < 640px  (sm)
  └─ Single column layout
  └─ Full-width buttons
  └─ Stacked sections
  └─ Font size: 14px (text-sm)

Tablet:    ≥ 640px  (sm:)
  └─ 2-column grid
  └─ Wider buttons
  └─ Side-by-side sections
  └─ Font size: 16px (text-base)

Desktop:   ≥ 1024px (lg)
  └─ Full multi-column layout
  └─ Wider cards
  └─ Spacing increases
  └─ Font size: 18px (text-lg)
```
